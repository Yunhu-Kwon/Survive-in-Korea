# VGG 개선 과정과 최종 제출 후보

최종 후보는 최신 운전자 5-fold CV + 전체/크롭 결합 + 얼굴 보정 0.5 + 클래스별 확률 보정입니다.
전체/크롭 테스트 확률은 각각 5개 모델 평균이며 두 결과를 1:1로 결합합니다.
최신 후보의 Kaggle 점수는 아직 확인 전입니다. 과거 최고 제출은 비교 기록으로 보존합니다.

|---|---|---:|---:|---:|

## 초기 6명 검증에서의 학습 개선

| 단계 | 변경 | 검증 정확도 | 검증 Log Loss |
|---|---|---:|---:|
| 1에폭 기준 모델 | ImageNet VGG16 features 고정, GAP 분류기 학습 | 57.03% | 1.57250 |
| 미세조정 | block 4–5 학습, AdamW·cosine·약한 증강 | 91.64% | 0.48113 |
| 온도 보정 | 운전자 교차 적합으로 예측 확률 보정 | 91.64% | 0.34781 |
| VGG 조합 + 얼굴 보정 | VGG16/BN-GAP 결합과 c0/c9 질량 재분배 | 93.49% | 0.24761 |
| 클래스별 보정 | L2 규제 편향 + 온도 | 95.02% | 0.19264 |

이 6명은 반복된 모델·에폭 선택에 사용한 개발 검증 집합입니다. 독립 최종 테스트 정확도가 아닙니다.

## 최신 최종 후보: 전체 26명 OOF 비교

각 운전자를 해당 base 모델의 학습에서 제외한 22,424장 예측으로 비교했습니다.
| 단계 | OOF 정확도 | OOF Log Loss |
|---|---:|---:|
| 전체 이미지 VGG16-BN | 90.14% | 0.33293 |
| 운전자 영역 크롭 단독 | 90.57% | 0.34419 |
| 전체/크롭 raw 확률 1:1 평균 | 91.13% | 0.32177 |
| 전체/크롭 + 온도 보정 | 91.13% | 0.27975 |
| 얼굴 보정 0.5 추가 | 91.72% | 0.25435 |
| 클래스별 보정 추가 (최종) | 91.80% | 0.25035 |

최종 선택: 크롭 0.5, 얼굴 보정 0.5, 클래스별 보정 적용.
같은 26명 비교에서 전체 이미지 + 얼굴/클래스별 보정(0.27121) 대비 최종 조합(0.25035)은 약 7.69% 개선됐습니다.
이 OOF 점수와 과거 6명 점수는 데이터 범위·모델이 달라 절대값을 직접 비교하지 않습니다.
고정 학습 설정은 이전 개발 실험의 영향을 받았고, 보정 교차 검증은 base 모델까지 다시 학습하는 완전한 nested CV는 아닙니다.
